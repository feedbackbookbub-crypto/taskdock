# Rebuild notes

This version adds a session-first FamsUp workflow:
- Dedicated persistent FamsUp browser profile.
- Dedicated persistent profile for each social account.
- Connection dashboard for login/setup.
- FamsUp task-sync workspace based on an authenticated browser session and visible task content.
- Task-specific account selection.
- Action assistance that highlights likely Like/Follow/Subscribe controls without clicking them.
- Completed-state checking and automatic proof screenshot.
- Existing SQLite-style local architecture retained.

The actual social engagement click remains human-confirmed.
